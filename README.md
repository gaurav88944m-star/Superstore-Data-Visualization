# 📊 Superstore Data Visualization Using Python

A beginner-friendly Data Science project that analyzes Superstore sales data and visualizes business insights using Python.

## 🚀 Project Overview

This project explores a Superstore dataset to understand sales and profit performance across different product categories. It uses Python libraries to analyze data, calculate important statistics, and create visual charts.

## 🛠️ Technologies Used

- **Python** — Core programming
- **Pandas** — Data analysis and manipulation
- **NumPy** — Numerical calculations
- **Matplotlib** — Data visualization
- **Git & GitHub** — Version control and project hosting

## ✨ Project Features

- Load and explore a CSV dataset
- Display dataset dimensions and sample records
- Calculate total, average, maximum, and minimum sales
- Analyze sales by product category
- Calculate profit by category
- Create a bar chart to compare category-wise sales
- Identify the category with the highest sales

## 📈 Key Insights

- **Highest Sales Category:** Technology
- **Total Sales:** Approximately 2.30 million
- **Dataset Size:** 9,994 rows and 21 columns

*Insights are based on the dataset used in this project.*

## ⚙️ How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/gaurav88944m-star/Superstore-Data-Visualization.git
```

**2. Open the project folder**

```bash
cd Superstore-Data-Visualization
```

**3. Install the required libraries**

```bash
python -m pip install pandas numpy matplotlib
```

**4. Run the Python program**

```bash
python Superstore_Visualization.py
```

Make sure the CSV dataset is in the same folder as the Python file.
